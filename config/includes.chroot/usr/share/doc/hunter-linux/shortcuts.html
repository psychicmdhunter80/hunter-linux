SMD LINUX

Keyboard shortcuts — version 1.0

The Super key (the Windows key) is the main modifier. Every shortcut below uses it, so nothing else on the desktop changes meaning.

Everyday use

Super + DApplication launcher (type part of a name, Enter to start)
Super + TabSwitch between open windows
Super + EnterOpen a terminal
Super + EOpen the file manager (Thunar)
Super + PDisplay settings (second monitor, resolution)
Super + F1This page

Windows

Super + Q ShiftClose the focused window
Super + FFull screen on and off
Super + arrow keysMove the focus between windows
Super + Shift + arrowsMove the focused window
Super + RResize mode: use the arrows, Enter or Esc to finish
Super + SpaceSwitch between tiled and floating
Super + SStack windows on top of each other
Super + WShow windows as tabs

Workspaces

Super + 1 … 0Go to workspace 1 … 10
Super + Shift + 1 … 0Move the focused window to that workspace

Sound, brightness and power

Volume keysVolume up, down, mute
Brightness keysScreen brightness on laptops that support it
Super + Shift + EPower menu: lock, log out, restart, shut down
Super + Shift + LLock the screen

The panel at the bottom of the screen has the application menu, the window list, workspaces, network and Bluetooth status, the clock, volume, battery percentage and the power menu.

Install or try SMD Linux. This live session runs entirely from the USB device and does not touch your internal drive. To install, use the Install SMD Linux icon on the desktop or in the application menu. To leave, choose Shut down from the power menu and remove the USB device.
