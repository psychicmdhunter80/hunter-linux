Keyboard shortcuts — version 1.5.0

The Search key (where a Caps Lock key normally sits on this Chromebook, and the Windows key on other keyboards) opens the application menu on its own. Everything else uses Alt as the modifier, so the browser keeps Ctrl and Alt + ←/→ for itself.

Everyday use

Search aloneApplication launcher (type part of a name, Enter to start)
Alt + DThe same launcher, if you prefer a combination
Alt + TabSwitch between open windows
Alt + EnterOpen a terminal
Alt + EOpen the file manager (Thunar)
Alt + PDisplay settings (second monitor, resolution)
Alt + ZVoice typing on and off (see below)
Alt + F1This page

Windows

Alt + F4 or Alt + Shift + QClose the focused window
Alt + FFull screen on and off
Alt + H J K LMove the focus left, down, up, right
Alt + Shift + H J K LMove the focused window
Alt + RResize mode: H J K L or the arrow keys, Enter or Esc to finish
Alt + SpaceSwitch between tiled and floating
Alt + SStack windows on top of each other
Alt + WShow windows as tabs

Workspaces

Alt + 1 … 0Go to workspace 1 … 10
Alt + Shift + 1 … 0Move the focused window to that workspace
Alt + Ctrl + ←/→Move the focused window to the previous/next workspace

Voice typing and text editing

Alt + ZStart listening; press it again to stop. The words are typed into whichever text field has the cursor.
Ctrl + ZUndo - unchanged, and still the application's own Undo while dictation is on
Ctrl + X / C / VCut, copy and paste
Ctrl + ASelect all

Voice typing recognises speech on this computer with the small English model that ships on the image, so it works with no network connection. A notification says listening when it starts and stopped when it stops. The microphone is open only between those two presses: recording and the recogniser both end when it is switched off, and nothing listens in the background. The same switch is in the application menu as Voice Typing. Dictation needs a quiet room and a working microphone; everything else about typing is unchanged.

Sound, brightness and power

Volume keysVolume up, down, mute - press the printed key, no Fn or other modifier (PipeWire)
Brightness keysDim and brighten on Chromebooks and laptops that support it
Ctrl + a top-row keyOn a Chromebook, sends the real function key to the application instead, so Ctrl + F10 is F10
Alt + Shift + EPower menu: lock, log out, restart, shut down
Alt + Shift + XLock the screen

The panel sits along the bottom edge with a black background and stays visible; full-screen video covers it. On a Chromebook the top row is not a function-key row: the volume, mute and brightness symbols are what those keys send, and their ordinary F-key meaning is on Ctrl plus the key. It holds the application menu, the window list, workspaces, network and Bluetooth status, the clock, volume, battery percentage and the power menu.
